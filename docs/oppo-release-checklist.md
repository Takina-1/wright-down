## 阶段 A：提交前必须完成（否则提不了审）

| # | 项目 | 打勾标准 |
|---|---|---|
| 1 | 主体资格 | 企业/个体工商户营业执照在有效期内，经营范围含互联网或软件开发 |

| 8 | OPPO 免责函 | OPPO 特有材料，其他平台不需要 |

## 阶段 B：隐私合规（90% 的驳回来自这里）

| # | 检查项 | 打勾标准 |
|---|---|---|
| 9 | 首次启动隐私弹窗 | 有明确「同意」/「不同意」两个按钮；**无默认勾选**；**不用"我知道了"** |
| 10 | 弹窗可读性 | 字号正常、有简体中文版、隐私政策链接可点 |
| 11 | 隐私政策独立 | 不是用户协议的一部分，有独立页面 |
| 12 | **录音单独同意** | 首次点录音时单独弹窗，**不与通用隐私弹窗合并** |
| 13 | 权限按需申请 | 首次启动不一次性要权限；点具体功能才申请对应权限 |
| 14 | 拒绝后不反复 | 用户拒绝后不重复弹窗、不每次重启再要、**App 仍可正常使用** |
| 15 | 权限可撤销 | 设置内有独立权限管理页，4 步内可撤回 |
| 16 | 敏感信息标识 | 隐私政策中录音等敏感信息**加粗/标星/下划线** |
| 17 | 告知要素完整 | 开发者名称+联系方式、处理目的/方式/种类/保存期限 |
| 18 | 数据境内存储 | OSS + 数据库全在**中国大陆境内**；转写用阿里云/腾讯云 ASR，**不用 OpenAI Whisper** |
| 19 | 第三方 SDK 清单 | 隐私政策列出所有 SDK 及用途；SDK 也要在 APP 备案申报 |
| 20 | 注销入口 | 设置页**一级可达**，二次确认，明确写"永久删除不可恢复" |
| 21 | 删除时限 | 隐私政策写明注销后数据（含备份）彻底清除时限（如 7 日） |
| 22 | 未成年人保护 | 若可能吸引未成年人，需青少年模式或相应声明 |
| 23 | 权限说明 | 每个敏感权限都要在应用内说明用途（不是只写在隐私政策） |

| # | 项目 | 打勾标准 |
|---|---|---|

## ⚠️ 三个最容易翻车的点

### ① 四名一致
```
软著:      XX日记 v1.0
App 名称:  XX日记          ✅
备案名称:  XX日记          ✅
安装包内:  XX日记          ✅
```
任何一个不一致 → 直接驳回。小米还规定应用名**每年只能改 2 次**，改名要重新提供软著。

### ② 权限申请时机
```
❌ 首次启动弹：麦克风 + 相册 + 存储 + 通知   → 违规
✅ 首次启动只弹隐私政策
✅ 点「🎤录音」→ 弹麦克风
✅ 点「📷拍照」→ 弹相机
✅ 点「导出」→ 弹存储
```

### ③ 隐私政策必须写清这 6 件事
```
1. 收集什么（录音文件、转写文本、图片、手机号）
2. 为什么收集（生成文字、多设备同步、账号登录）
3. 怎么存（加密、境内、哪个服务商）
4. 存多久（删日记即删音频；注销后 7 日内彻底清除含备份）
5. 谁能看到（只有你；我们不看内容；不用于模型训练）
6. 你的权利（查阅、删除、更正、撤回同意、注销）
```

## 隐私政策模板骨架（给写政策用）

```
XX日记 隐私政策
生效日期：2026-XX-XX

一、我们是谁
   开发者名称 / 联系方式（与开发者认证信息一致）

二、我们收集什么信息
   - 录音文件（用于生成文字记录）
   - 录音转写后的文本
   - 日记正文、图片、标签
   - 手机号或邮箱（仅用于账号登录）
   - 设备标识、IP（用于同步与安全）

三、我们如何使用
   - 生成日记文字
   - 多设备云同步
   - 账号登录与找回

四、存储位置与期限
   - 全部存储于中华人民共和国境内
   - 删除日记时同步删除对应音频
   - 注销账号后 7 日内彻底清除（含备份）

五、我们不做什么
   - 不读取你的日记内容
   - 不用于模型训练
   - 不向第三方出售

六、权限说明
   - 麦克风：录制语音日记
   - 相机/相册：添加日记配图
   - 存储：导出与备份
   - 通知：日记提醒

七、你的权利
   查阅 / 更正 / 删除 / 撤回同意 / 导出 / 注销

八、未成年人保护

九、联系我们
```

## 主体选择备忘

| 开发者类型 | OPPO 可上架品类 |
|---|---|
| **企业开发者** | Android 应用/游戏、快应用、OPPO 小游戏、主题字体、锁屏杂志、短视频、IoT |
| **个人开发者** | 快应用、主题、壁纸、动态壁纸、铃声、锁屏杂志、短视频 |

> ⚠️ **Android 应用（普通 APP）必须企业/个体工商户主体。**
> 个人开发者唯一能走的是**快应用**。
>
> 其他主流市场同样限制：小米官方明确「暂不接受个人开发者账号申请」；华为/应用宝/vivo 均需企业主体。
>
> **成本参考**：个体工商户注册 200–500 元（代理）或自行办理免费；拿到执照后 OPPO/小米/华为全通。
