- [功能需求与开发方案模板](templates/功能需求模板-feature-spec-template.md)：需求、验收标准、实现方案、任务和测试计划写在同一份文档。

模板和命名示例不代表已经立项、开发或测试。当前已建立 Flutter Android 工程，F001 的实施及验收进度见功能台账。

## 文档更新规则

- 一个信息只有一个主要维护位置：功能状态维护在任务台账，测试结果维护在报告，共用架构维护在产品设计。
- 参考资料中的建议不自动成为产品决策。采用后更新功能方案；影响共用架构时同时更新产品设计，并记录原因。
- 文件移动或改名时，同时修复引用和索引；通过版本控制追踪历史，不创建“最终版”“最终版2”等副本。
