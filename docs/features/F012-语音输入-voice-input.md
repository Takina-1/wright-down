## 1. 用户场景与目标

打字慢的时候，用户想说一句话把当天记下来。语音输入让用户按住说一段话，转成文字存进日记，是「30 秒记完」这个定位（C 语音优先）的核心能力。

本条目目前**只是待办登记**：把要做什么、有什么约束、为什么现在不做记录清楚，等用户决定排期时可以直接开工。

## 2. 范围与边界

- 本次实现：**无**。本次只记录待办。
- 若将来实施，需要覆盖的范围（来自 [产品设计](../产品设计-product-design.md) §3、§6）：
  - 端侧录音 + 端侧 ASR 先转写 → 文本立刻入库（保证离线可写）。
  - 云端 ASR 异步精修 → 用户确认后替换。
  - 字段：`content` / `rawTranscript`(本地) / `audioUri`(本地) / `cloudAudioKey` / `cloudTranscript` / `transcriptSource`。
  - 分段规则：显式「下一条」按钮 + 静默超时（默认 12 秒）双信号，每段独立 Entry。
  - 权限时机：点击录音按钮后才申请麦克风；拒绝后给打字替代路径，绝不反复申请。
  - 音频上传 COS（私有 bucket，服务端代理读写）。

- 本次不实现：全部（见上）。

- 前置依赖：F001（本地记录）。

- 未决定的问题及影响（均来自产品设计 §二「语音相关待定」）：
  - 云端转写文本是自动替换还是用户确认 → 倾向用户确认。
  - 是否做端到端加密（决定以后能不能接 AI 润色）。
  - 音频是否支持回放（影响存储成本 + 鉴权复杂度）。
  - 云端 ASR 成本压降（端侧置信度低时才走云端 / 低频存储 / 30 天转写后删音频）。

## 3. 合规与上架约束（实施前必须先解决）

产品设计 §6 已列明，这是本功能与其他功能最大的差别：

- COS 必须私有 bucket，音频访问单独鉴权（不能拿到日记列表就能拉所有音频）。
- 首次启动隐私政策弹窗 + 首次点录音**单独同意弹窗**（不可合并）。
- 设置里提供「云端同步录音」开关，可随时关闭。
- 全部存储于中国大陆境内；转写用国内厂商（阿里云/腾讯云 ASR），不用 OpenAI Whisper。
- 隐私政策必须写明：存储期限、删除机制、是否用于模型训练。
- OPPO 上架清单另有录音相关条目，实施时需同步核对。
