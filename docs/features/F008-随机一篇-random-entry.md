## 1. 用户场景与目标

打开回顾页时，顶部除了连续天数，还想有一个「随便看看」入口：从已有日记里随机抽一篇，让用户在不知道该看什么时有个轻量的起点。纯本地计算，不依赖网络、不新增数据字段、不引入服务器。

## 2. 范围与边界

- 本次实现：
  - `domain` 层新增纯函数 `pickRandomEntry`：从一组未删除条目里随机抽一条。
  - 回顾页顶部新增「🎲随便看看」卡片：显示抽中条目的摘要与日期，点击进详情，提供「换一篇」重新抽。
  - 空状态：无记录时卡片显示引导。
  - 边界（空数据、单条、多条、固定种子可复现）写进验收标准并配测试。

- 本次不实现：
  - 历史回顾卡片（去年今天、月度回顾）——见产品设计 §二延后项。
  - 关键词云、AI 情绪分析。
  - 按标签/日期范围筛选后随机。

- 前置依赖：F001（本地记录）、F005（删除记录与回收站，提供未删除条目过滤）。

- 未决定的问题及影响：无。

## 5. 实现方案

### 5.1 页面与状态变化

回顾页（TimelinePage）顶部新增一张卡片，与连续天数卡片上下排列：

```text
┌─────────────────────────────┐
│ 🎲 随便看看                  │
│ 抽中条目摘要…                 │
│ 2026-10-28        [换一篇]   │
└─────────────────────────────┘
```

- 卡片文案、emoji 由 UI 层决定；domain 层只提供抽中的 `Entry`。
- 抽中逻辑：打开回顾页时抽一次，点「换一篇」重新抽。

### 5.2 数据流、模型与接口

domain 层新增纯函数（零框架依赖，符合 Local-First 三条铁律）：

```dart
/// 从一组未删除条目里随机抽一条。
///
/// [entries] 应为未删除条目；空集返回 null。
/// [random] 用于测试注入固定种子，生产默认取系统随机源。
Entry? pickRandomEntry(List<Entry> entries, {Random? random});
```

算法：
1. 空集返回 null。
2. 用 `Random`（默认系统源，测试可注入固定种子）取索引 `[0, entries.length)`。
3. 返回对应条目。

回顾页从 `repository.exportAll()` 取全部条目，过滤 `!isDeleted`，调用 `pickRandomEntry`。

### 5.3 受影响模块／文件

```text
client/lib/src/domain/random_entry.dart              新增：pickRandomEntry 纯函数
client/lib/src/ui/timeline_page.dart                 回顾页顶部新增随机一篇卡片
client/test/domain/random_entry_test.dart            新增：纯函数单测覆盖 AC-07
client/test/ui/timeline_page_random_test.dart         新增：组件测试覆盖 AC-01~AC-06
```

新增依赖：无。

### 5.4 离线、权限拒绝、失败与恢复

- 纯本地计算，无网络依赖，离线照常可用。
- 纯函数无 I/O，不会失败；空集返回 null 而非抛异常。

### 5.5 数据迁移与兼容性

- 不新增数据库字段、不升 schema、不改备份格式。
- 与 [产品设计](../产品设计-product-design.md) 的差异：无。产品设计 §11 把「🎲随便看看」列为回顾页顶部卡片之一，本次落实该入口。

- 实际实现路径：按第 6 节任务表顺序完成 T1–T4，全部在 `feat/F008-random-entry` 分支（从 main 的 `88a4f22` 开出）。T1 纯函数 + 域层单测；T2 回顾页顶部随机一篇卡片（`randomSeed` 做成可注入参数，生产默认系统随机源，组件测试固定种子；`onRandomShow` 回调跳详情）；T3 全量检查与构建；T4 真机验收（Xiaomi 2211133C / Android 15，adb 驱动）。
- 实际检查命令（第 1 轮，宿主侧）：
  ```bash
  cd client
  flutter analyze                      # No issues found!
  flutter test                         # 314 项全部通过（新增 6 域层 + 7 组件）
  flutter build apk --debug            # √ Built build/app/outputs/flutter-apk/app-debug.apk
  ```
- 实现细节与偏差：
  - 「换一篇」必然换到不同条目：`pickRandomEntry` 加 `excludeId` 参数，换一篇时排除当前展示那条的 ID（按 ID 而非引用比较——`exportAll` 每次返回新实例，引用比较失效）。首次抽取不排除。
  - 回顾页整页改成单个滚动 ListView（页眉 + 随机一篇 + 连续天数 + 时间轴一起滚动）。原布局页眉与两张卡片固定在 Expanded 时间轴之上，撑高后把时间轴首条推到屏幕外（小屏真机同样看不到首条），且固定高度在测试视口触发 RenderFlex 溢出。合并成单列表后两者都消失，属预期行为。
  - 随机卡片空状态文案用「翻开第一页，开始记录」，与时间轴空状态「还没有记录」区分，避免文案撞车。
  - 随机卡片正文走 `_snippet` 截断（20 字），与时间轴 ListTile 的正文撞同一文本：回顾页条目断言统一收窄到 ListTile（随机卡片正文在 InkWell 里、不是 ListTile，不会命中）。
  - 视口相关测试加高视口（900×3000）让被卡片推下去的条目可见。
- 已知限制与未完成项：
  - 随机卡片本期只展示摘要+日期，点卡片正文跳详情（由 HomePage 接线 onRandomShow → edit）。
  - 不做按标签/日期范围筛选后随机。
