# F003：保留已合并的特性分支

- 创建日期：2026-10-29

## 1. 目标与范围

特性分支合并到 `main` 后继续保留本地和远程分支，便于查看分支列表、追踪功能历史和定位对应提交。分支删除不作为合并后的自动清理步骤。

本次只修改项目规则，不恢复已经删除的 F002 分支，不新增远程分支保护或自动归档机制。

## 2. 验收标准

| 编号 | 场景 | 预期结果 |
|---|---|---|
| AC-01 | 特性分支成功合并到 `main` | 本地特性分支继续存在，不自动执行 `git branch -d` 或 `git branch -D` |
| AC-02 | 特性分支已经推送到远程 | 合并后不自动删除远程分支 |
| AC-03 | 需要删除已合并特性分支 | 只有用户明确要求删除时才执行删除操作 |
| AC-04 | AI 开发助手进入项目 | `AGENTS.md`、`CLAUDE.md` 和开发流程表达一致的分支保留规则 |
